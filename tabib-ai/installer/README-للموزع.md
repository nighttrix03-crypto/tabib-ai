# طبيب AI — حزمة التثبيت لويندوز

- `TabibAI-Setup.exe` ملف تثبيت واحد لويندوز x64. انسخه إلى مساحة/موقع تنزيل عام ليتمكن الآخرون من تنزيله.
- المثبّت ينسخ التطبيق لمجلد المستخدم، ويضيف اختصاراً إلى سطح المكتب وقائمة ابدأ، ثم ينزّل مُثبّت Ollama من الموقع الرسمي ويتحقق من توقيع شركة Ollama قبل تشغيله.
- بعد موافقة المستخدم على شروط MedGemma، يطلب المثبّت تنزيل النموذج من Ollama. حجمه نحو 3.3 GB، إضافة إلى مُثبّت Ollama. تظهر حالة التنزيل داخل نافذة التثبيت.
- بعد التثبيت، يعمل الذكاء الاصطناعي محلياً على جهاز كل مستخدم. لا يحتاج المستخدم إلى API key.
- يتطلب Windows x64 واتصال الإنترنت أثناء التثبيت وتخزيناً وذاكرة كافيين لتشغيل النموذج.

أوزان MedGemma غير مضمنة في ملف التثبيت. يجب على كل مستخدم مراجعة شروط Google والموافقة عليها قبل تنزيلها. لا تستخدم المخرجات للتشخيص السريري أو العلاج؛ النموذج غير معتمد لهذه القرارات.
