# طبيب AI v1.0.0 — أصول الإصدار

مساعد صحي عربي لسطح المكتب يعمل محلياً على Windows عبر Ollama + MedGemma، دون مفتاح API.

## الأصول

| الملف | الوصف |
| --- | --- |
| `TabibAI-Setup.exe` | مثبّت Windows x64. يتضمن التطبيق، وينزّل Ollama الرسمي ويتحقق من توقيعه، ثم ينزّل MedGemma بعد موافقة المستخدم على شروط Google. |
| `TabibAI.exe` | التطبيق وحده (self-contained) لمن يريد تشغيله دون مثبّت. |
| `TabibAI-source.zip` | الكود المصدري الكامل (C# / .NET 10 WinForms). |
| `SHA256SUMS-v1.0.0.txt` | بصمات SHA-256 للتحقق من سلامة الملفات. |

## التحقق من التنزيل

```powershell
Get-FileHash .\TabibAI-Setup.exe -Algorithm SHA256
```

قارن الناتج بسطر `TabibAI-Setup.exe` في `SHA256SUMS-v1.0.0.txt`.

## المتطلبات

- Windows x64، اتصال بالإنترنت أثناء الإعداد الأول، ~3.3 GB مساحة للنموذج.
- بعد الإعداد يعمل التحليل محلياً على جهازك؛ لا تُرسل الحالات إلى أي خادم لهذا المشروع.

## السلامة

هذا التطبيق ليس جهازاً طبياً ولا أداة تشخيص معتمدة. MedGemma نموذج للمطوّرين ولم يُتحقق من صلاحيته سريرياً لهذا التطبيق. لا تستخدم المخرجات وحدها للتشخيص أو العلاج؛ راجع مختصاً صحياً، واطلب المساعدة الطارئة فوراً عند أعراض الخطر.

الأوزان غير مضمنة في هذا الإصدار: يطلب المُثبّت موافقتك على [شروط Google HAI-DEF](https://developers.google.com/health-ai-developer-foundations/terms) قبل تنزيلها من Ollama.
